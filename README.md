# HM Lab Reserve — Frontend Demo (presentation)

Open **index.html** (double-click). No server, PHP or database needed. Bookings are stored in your browser.

## Suggested demo flow
1. Click **Load sample bookings** (footer) — the **Live Booking Board** fills up.
2. Click **Book Station**, pick a date/shift (taken shifts are greyed out), submit → the booking appears on the board instantly.
3. Try booking the same station/shift again → blocked. 
4. Flip the **Student / Admin switch** in the navbar → the Custodian Dashboard (stats, 7-day schedule, activity, charts, requests). Approve or reject → status changes on the student side. Flip back to continue as a student.
5. **My Reservations** → enter `2024-00123` (sample student) or your own ID.
6. **Reset demo** clears everything.

Files: index.html · style.css · mock-api.js (fake backend) · script.js (student) · admin.js (custodian)
